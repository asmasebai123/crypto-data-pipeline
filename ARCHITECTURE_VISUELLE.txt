📊 PANDAS (Actuellement: 3,633 lignes)
───────────────────────────────────────────────────────────────────────────────

  1 ordinateur → 1 CPU → 5 secondes

  from pandas import read_sql, groupby

  df = read_sql("SELECT * FROM raw_crypto_prices", conn)

  ├─ TRANSFORMATION 1: Hourly Average
  │  └─ df.groupby(['coin_id','hour']).agg({'current_price':'mean'})
  │     → transform_hourly_avg
  │
  ├─ TRANSFORMATION 2: Daily Volume
  │  └─ df.groupby(['coin_id','day']).agg({'total_volume':'sum'})
  │     → transform_daily_volume
  │
  └─ TRANSFORMATION 3: Daily Ranking
     └─ df.groupby('coin_id')['current_price'].rank()
        → transform_daily_ranking


⚡ SPARK (Si > 50k lignes, activation automatique)
───────────────────────────────────────────────────────────────────────────────

  10 ordinateurs → 10 CPUs → 15 secondes (mais traite 100x plus de données!)

  from pyspark.sql import SparkSession
  from pyspark.sql.functions import *

  spark = SparkSession.builder.appName("crypto").getOrCreate()
  df = spark.read.jdbc(...)

  ├─ TRANSFORMATION 1: Hourly Average (Distributed)
  │  └─ df.groupBy('coin_id','hour').agg(avg('current_price'))
  │     → transform_hourly_avg (résultat IDENTIQUE)
  │
  ├─ TRANSFORMATION 2: Daily Volume (Distributed)
  │  └─ df.groupBy('coin_id','day').agg(sum('total_volume'))
  │     → transform_daily_volume (résultat IDENTIQUE)
  │
  └─ TRANSFORMATION 3: Daily Ranking (Distributed)
     └─ df.groupBy('coin_id').agg(rank('current_price'))
        → transform_daily_ranking (résultat IDENTIQUE)
